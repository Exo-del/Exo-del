### Featured

**[SeedBrain-CRS](https://github.com/Exo-del/SeedBrain-CRS)** — AI-powered crop recommendation desktop app

- **Input:** N/P/K, temperature, humidity, rainfall, pH → **Output:** best crop to grow
- **Model:** XGBoost trained on real FAO fertilizer survey data, not synthetic data
- **Extras:** Local explanations via llama.cpp, offline-first, Docker-ready
